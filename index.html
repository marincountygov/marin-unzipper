About Marin Unzipper

Marin Unzipper opens ZIP files in your browser. It can decrypt password-protected ZIP files and decompress the files inside them.

Files remain only on your device. This page does not upload the ZIP file, the extracted files, or the password.

How to use it

  1. Choose or drop a ZIP file.
  2. Enter the password if the ZIP file is encrypted.
  3. Select Decrypt and list files.
  4. Download one file at a time, or check multiple files and download them together as a new unencrypted ZIP.

About the unencrypted ZIP download

When you select multiple extracted files, Marin Unzipper creates a new ZIP file without password protection. This is meant for workflows where the original encrypted ZIP needs to be opened and then repackaged for a system that does not accept encrypted ZIP files.

Compatibility

Marin Unzipper uses a local zip.js library. It supports standard ZIP files and WinZip AES-encrypted ZIP files when the correct password is provided.

Security notes

Only extract files from ZIP files you trust. Do not include sensitive information in file names unless your department has approved that naming format.

Updates

Marin Unzipper does not load update data automatically.
